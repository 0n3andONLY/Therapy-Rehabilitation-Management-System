# Therapy Rehabilitation Management System

## Project Overview
The Therapy Rehabilitation Management System is a database management project designed to manage patients, therapists, appointments, therapy plans, rehabilitation sessions, exercises, medical records, patient progress, and billing.

## Database
- **DBMS:** MySQL
- **Database name:** `therapy_rehabilitation`
- **Tables:** 11
- **Views:** 6
- **Stored procedures:** 7
- **Stored functions:** 5
- **Triggers:** 2

## Main Features
- Patient and therapist record management
- Appointment scheduling and status validation
- Therapy plan and rehabilitation session management
- Exercise tracking for therapy sessions
- Medical records and patient progress tracking
- Bill management and billing calculations
- Stored procedures and functions for common database operations
- Triggers for validating appointment status, pain level, and strength score

## Project Files
- `database/therapy_rehabilitation_backup.sql` — SQL database backup containing schema, data, views, stored routines, and triggers.
- `documentation/` — Project report and supporting documentation.

## Setup Instructions
1. Install MySQL Server.
2. Create or select a suitable MySQL database.
3. Import the SQL backup into MySQL.
4. Verify the tables, views, stored procedures, functions, and triggers.
5. Run the SQL queries and stored routines to test the project.

## Notes
This project focuses on the database/backend component. The backup should be tested in a separate database before final submission.
